# Налаштування бази даних для різних режимів

Цей проект підтримує роботу з двома різними базами даних залежно від режиму налагодження:

## 🌍 Режими роботи

### 🔧 DEBUG_MODE=TRUE (Режим налагодження)
- **База даних**: SQLite (локальна)
- **Файл**: `./data/gameclub_local.db`
- **Призначення**: Локальна розробка та тестування
- **Переваги**: Швидка робота, незалежність від сервера

### 🚀 DEBUG_MODE=FALSE (Продакшн режим)
- **База даних**: PostgreSQL (серверна)
- **Призначення**: Робочий сервер
- **Переваги**: Надійність, масштабованість

## ⚙️ Налаштування

### 1. Створення .env файлу
```bash
cp env.example .env
```

### 2. Налаштування режиму налагодження
Відредагуйте файл `.env` і встановіть:
```env
# Для локальної розробки
DEBUG_MODE=TRUE

# Для продакшн сервера
DEBUG_MODE=FALSE
```

### 3. Ініціалізація локальної бази даних
```bash
python init_local_db.py
```

## 🔄 Перемикання режимів

### Простий спосіб
Просто змініть значення `DEBUG_MODE` в файлі `.env`:

```env
# Для локальної розробки
DEBUG_MODE=TRUE

# Для продакшн сервера  
DEBUG_MODE=FALSE
```

Після зміни перезапустіть бота.

### Автоматичне створення .env файлу
```bash
python create_env.py
```

Цей скрипт створить `.env` файл з правильним кодуванням.

## 📁 Структура файлів

```
micro_hero_bot/
├── data/
│   ├── gameclub.db          # Оригінальна база (резервна копія)
│   └── gameclub_local.db    # Локальна база для розробки
├── config.py                # Конфігурація з підтримкою DEBUG_MODE
├── database/
│   └── database.py          # Підключення до БД
├── init_local_db.py         # Ініціалізація локальної БД
├── create_env.py            # Створення .env файлу
└── .env                     # Змінні середовища
```

## 🛡️ Безпека

- **Локальна розробка**: Всі зміни залишаються на вашому комп'ютері
- **Продакшн**: Будьте обережні - зміни впливають на робочий сервер
- **Резервні копії**: Регулярно створюйте резервні копії важливих даних

## 🔍 Перевірка конфігурації

```bash
python config.py
```

Ця команда покаже:
- Поточне середовище
- Тип бази даних
- Налаштування бота
- Статус конфігурації

## 🚨 Важливі зауваження

1. **Завжди перевіряйте DEBUG_MODE** перед запуском бота
2. **Не тестуйте на продакшн БД** - використовуйте локальну
3. **Створюйте резервні копії** перед важливими змінами
4. **Використовуйте git** для відстеження змін коду
5. **Зміни в .env файлі** вимагають перезапуску бота

## 🆘 Вирішення проблем

### Проблема: "База даних не знайдена"
```bash
python init_local_db.py
```

### Проблема: "Невірний режим"
Перевірте значення `DEBUG_MODE` в `.env` файлі:
- `DEBUG_MODE=TRUE` - локальна SQLite база
- `DEBUG_MODE=FALSE` - серверна PostgreSQL база

### Проблема: "Конфлікт з серверною БД"
Переконайтеся, що `DEBUG_MODE=TRUE` в `.env` файлі

### Проблема: "Помилки кодування в .env"
```bash
python create_env.py
```
