# Виправлення проблеми з зникаючими імейджами

## Проблема
Після деплою на Railway імейджі ігор зникають, хоча посилання в базі даних залишаються.

## Причина
Railway - це stateless платформа. При кожному деплої контейнер пересоздається і всі локальні файли втрачаються.

## Рішення
Використовувати Railway Persistent Volume - постійне сховище файлів.

## Налаштування (2 хвилини)

### 1. Volume вже налаштований!

Volume для імейджів вже налаштований в файлі `railway.json`:
```json
{
  "name": "images-storage",
  "mountPath": "/app/static/images"
}
```

### 2. Деплойте зміни

```bash
git add .
git commit -m "Setup Railway persistent volume for images"
git push
```

### 3. Перевірте роботу

1. Додайте гру з імейджем через бота
2. Зробіть деплой: `git push`
3. Перевірте, що імейдж залишився ✅

**Volume автоматично створиться при деплої!**

## Готово!

Тепер імейджі зберігаються в постійному сховищі Railway і не зникають після деплою.

## Як це працює

- Імейджі зберігаються в `/app/static/images/`
- Ця папка підключена до Railway Persistent Volume
- Файли НЕ видаляються при деплої
- Код залишається простим - звичайне локальне збереження

## Troubleshooting

**Файли все ще зникають?**
- Перевірте, що volume створений і підключений
- Переконайтеся, що Mount Path: `/app/static/images`
- Перевірте логи Railway

**Недостатньо місця?**
- Збільшіть розмір volume в налаштуваннях Railway
