# Telegram Bot для менеджменту ігротеки (Герої на полицях)

## Опис проекту

Telegram бот для управління ігротекою, створений з використанням aiogram та SQLModel. Бот дозволяє користувачам переглядати розклад ігор та реєструватися на них, а адміністраторам - керувати іграми та розкладом.

## Технології

- **aiogram** - фреймворк для створення Telegram ботів
- **SQLModel** - ORM для роботи з базою даних
- **PostgreSQL** - база даних для продакшн сервера (підтримка asyncpg)
- **SQLite** - локальна база даних для розробки (підтримка aiosqlite)
- **Python 3.8+**

## 🌍 Режими розробки

Проект підтримує роботу з двома режимами:

### 🔧 DEBUG_MODE=TRUE (Режим налагодження)
- **База даних**: SQLite (`./data/gameclub_local.db`)
- **Призначення**: Локальна розробка та тестування
- **Переваги**: Швидка робота, незалежність від сервера

### 🚀 DEBUG_MODE=FALSE (Продакшн режим)
- **База даних**: PostgreSQL (серверна)
- **Призначення**: Робочий сервер
- **Переваги**: Надійність, масштабованість

**Детальна інструкція**: [DATABASE_SETUP.md](DATABASE_SETUP.md)

## Функціональна структура

### Ролі користувачів

#### 1. Звичайний користувач

- Реєстрація на гру

#### 2. Адміністратор

- Перегляд статистики реєстрацій

## Детальна функціональність

### Для звичайних користувачів

#### Головне меню
- **📅 Розклад ігор** - перегляд ігор на найближчі 7 днів
- **🎮 Мої записи** - перегляд активних записів користувача
- **ℹ️ Про ігротеку** - інформація про клуб

#### Розклад ігор
- Відображення ігор по днях (найближчі 7 днів)
- Для кожної гри показується:
  - Назва гри
  - Час проведення
  - Кількість гравців (зайнято/всього)
  - Статус реєстрації користувача
- Кнопка "Записатися" / "Скасувати запис"

#### Детальна інформація про гру
- Зображення гри
- Опис
- Кількість гравців (від X до N)
- Середня тривалість партії
- Список записаних гравців
- Кнопки дій (записатися/скасувати)

#### Мої записи
- Список активних записів
- Можливість скасувати запис
- Історія минулих ігор

### Для адміністраторів

#### Адмін-панель (доступна тільки адмінам)
- **🎮 Управління іграми** - додавання/редагування ігор
- **📅 Розклад** - створення та управління розкладом
- **📊 Статистика** - перегляд статистики реєстрацій
- **👥 Користувачі** - управління користувачами

#### Управління іграми
- **Додати гру** - створення нової гри
- **Редагувати гру** - зміна інформації про гру
- **Видалити гру** - видалення гри з бази
- **Список ігор** - перегляд всіх ігор

#### Створення нової гри
1. Назва гри
2. Завантаження зображення
3. Мінімальна кількість гравців
4. Максимальна кількість гравців
5. Середня тривалість партії (хвилини)
6. Опис гри

#### Розклад ігор
- **Додати гру в розклад** - створення нового запису в розкладі
- **Редагувати розклад** - зміна існуючих записів
- **Видалити з розкладу** - видалення запису

#### Створення запису в розкладі
1. **Вибір дати**:
   - Швидкий вибір (найближчі 7 днів)
   - Введення дати вручну
2. **Вибір часу**:
   - Час початку
   - Час закінчення
3. **Вибір гри**:
   - Зі списку існуючих ігор
   - Створення нової гри "на льоту"

#### Статистика
- Загальна кількість реєстрацій
- Найпопулярніші ігри
- Статистика по днях тижня
- Активність користувачів

#### Сповіщення адміністратора
При реєстрації користувача на гру адміністратор отримує повідомлення:
```
🎮 Нова реєстрація!

👤 Гравець: @username (Ім'я)
🎯 Гра: Назва гри
📅 Дата: ДД.ММ.РРРР
⏰ Час: ЧЧ:ММ - ЧЧ:ММ
👥 Місця: 3/6

Список гравців:
1. @user1 (Ім'я1)
2. @user2 (Ім'я2)  
3. @user3 (Ім'я3)
```

## Структура бази даних (SQLModel)

### Моделі даних

#### User (Користувач)
```python
class User(SQLModel, table=True):
    id: int = Field(primary_key=True)
    telegram_id: int = Field(unique=True, index=True)
    username: Optional[str] = None
    first_name: str
    last_name: Optional[str] = None
    is_admin: bool = Field(default=False)
    created_at: datetime = Field(default_factory=datetime.utcnow)
```

#### Game (Гра)
```python
class Game(SQLModel, table=True):
    id: int = Field(primary_key=True)
    name: str = Field(index=True)
    description: str
    min_players: int
    max_players: int
    avg_duration: int  # в хвилинах
    image_path: Optional[str] = None
    is_active: bool = Field(default=True)
    created_at: datetime = Field(default_factory=datetime.utcnow)
```

#### GameSession (Сесія гри в розкладі)
```python
class GameSession(SQLModel, table=True):
    id: int = Field(primary_key=True)
    game_id: int = Field(foreign_key="game.id")
    date: date
    start_time: time
    end_time: time
    created_by: int = Field(foreign_key="user.id")
    created_at: datetime = Field(default_factory=datetime.utcnow)
```

#### Registration (Реєстрація на гру)
```python
class Registration(SQLModel, table=True):
    id: int = Field(primary_key=True)
    user_id: int = Field(foreign_key="user.id")
    session_id: int = Field(foreign_key="gamesession.id")
    registered_at: datetime = Field(default_factory=datetime.utcnow)
    is_active: bool = Field(default=True)
```

- `/start` - початок роботи з ботом

### Callback дані
- `schedule_*` - розклад ігор

## 🚀 Встановлення та запуск

### Варіант 1: Локально (для розробки)

#### Використовуючи uv (рекомендовано)

```bash
# Встановіть uv
pip install uv

# Створіть віртуальне середовище
uv venv

# Активуйте середовище
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Git Bash/Linux:
source .venv/Scripts/activate

# Встановіть залежності
uv pip install -e .

# Створіть .env файл
cp env.example .env
# Відредагуйте .env - додайте BOT_TOKEN, ADMIN_IDS та встановіть DEBUG_MODE=TRUE

# Ініціалізуйте локальну базу даних (для режиму налагодження)
python init_local_db.py

# Перевірте конфігурацію
python config.py

# Запустіть бота
python main.py
```

#### Використовуючи Docker

```bash
# Створіть .env файл
cp env.example .env
# Відредагуйте .env

# Запустіть через Docker Compose
docker-compose up --build
```
