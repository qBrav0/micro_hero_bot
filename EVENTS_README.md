# Система подій для ігротеки

## Огляд

Система подій дозволяє створювати та управляти одноразовими заходами, які відображаються в розкладі разом з ігровими сесіями. Події мають схожу функціональність з іграми, але є незалежними заходами.

## Функціональність

### Для користувачів:
- **Перегляд подій** - окремий розділ "🎪 Події" в головному меню
- **Реєстрація на події** - з можливістю скасування
- **Мої події** - перегляд зареєстрованих подій ("📋 Мої події")
- **Інтеграція в розклад** - події відображаються в розкладі разом з іграми
- **Топ-10** - події враховуються в статистиці активності

### Для адміністраторів:
- **Створення подій** - через адмін-панель "🎪 Управління подіями"
- **Редагування подій** - зміна всіх параметрів
- **Управління учасниками** - перегляд списку, кік учасників
- **Видалення подій** - з автоматичним сповіщенням учасників

## Структура бази даних

### Таблиця Event
```sql
CREATE TABLE event (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title VARCHAR NOT NULL,              -- Назва події
    description VARCHAR NOT NULL,        -- Опис події
    min_participants INTEGER NOT NULL,   -- Мінімальна кількість учасників
    max_participants INTEGER NOT NULL,   -- Максимальна кількість учасників
    date DATE NOT NULL,                  -- Дата проведення
    start_time TIME NOT NULL,            -- Час початку
    end_time TIME NOT NULL,              -- Час закінчення
    payment_type VARCHAR DEFAULT 'included', -- Тип оплати
    image_file_id VARCHAR,               -- Telegram file_id для зображення
    is_active BOOLEAN DEFAULT 1,        -- Чи активна подія
    created_by INTEGER NOT NULL,         -- ID користувача, який створив
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (created_by) REFERENCES user (id)
);
```

### Таблиця EventRegistration
```sql
CREATE TABLE eventregistration (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,            -- ID користувача
    event_id INTEGER NOT NULL,           -- ID події
    registered_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    is_active BOOLEAN DEFAULT 1,        -- Чи активна реєстрація
    FOREIGN KEY (user_id) REFERENCES user (id),
    FOREIGN KEY (event_id) REFERENCES event (id)
);
```

## Файли системи

### Моделі
- `database/models.py` - додані моделі `Event` та `EventRegistration`

### CRUD операції
- `database/crud.py` - додані функції для роботи з подіями:
  - `create_event()`
  - `get_event()`
  - `get_all_events()`
  - `get_upcoming_events()`
  - `get_events_by_period()`
  - `update_event()`
  - `delete_event()`
  - `create_event_registration()`
  - `get_event_registrations()`
  - `cancel_event_registration()`
  - `check_user_registered_for_event()`

### Сервіси
- `services/event_service.py` - основний сервіс для роботи з подіями
- `services/combined_schedule_service.py` - сервіс для об'єднаного розкладу (ігри + події)

### Обробники
- `handlers/event.py` - обробники для подій (адмін та користувач)
- `handlers/user.py` - додані обробники для інтеграції подій в розклад
- `handlers/common.py` - оновлений топ-10 для включення подій

### Клавіатури
- `keyboards/admin_keyboards.py` - додано меню управління подіями
- `keyboards/inline_keyboards.py` - додані inline клавіатури для подій
- `keyboards/user_keyboards.py` - оновлено головне меню

## Встановлення

1. Запустіть міграцію для створення таблиць:
```bash
python add_events_migration.py
```

2. Перезапустіть бота для завантаження нових модулів.

## Використання

### Створення події (адмін)
1. Перейдіть в "⚙️ Адмін-панель"
2. Оберіть "🎪 Управління подіями"
3. Натисніть "➕ Створити подію"
4. Заповніть всі необхідні поля:
   - Назва події
   - Опис
   - Дата та час
   - Кількість учасників
   - Тип оплати
   - Зображення (опціонально)

### Реєстрація на подію (користувач)
1. Перейдіть в "🎪 Події" або "📅 Розклад ігор"
2. Оберіть подію зі списку
3. Натисніть "✅ Зареєструватися"

### Перегляд своїх подій
1. Перейдіть в "📋 Мої події"
2. Перегляньте список зареєстрованих подій

## Типи подій

Система підтримує різні типи подій:
- **Турніри** - змагальні заходи
- **Майстер-класи** - навчальні заходи
- **Презентації** - демонстрації нових ігор
- **Зустрічі** - неформальні збори
- **Спеціальні заходи** - унікальні події

## Інтеграція з існуючою системою

- **Розклад** - події відображаються разом з іграми
- **Топ-10** - враховуються в статистиці активності
- **Нагадування** - можуть бути додані в майбутньому
- **Сповіщення** - автоматичні повідомлення при змінах

## Майбутні покращення

- Система нагадувань для подій
- Категорії подій
- Повторювані події
- Обмеження за віком
- Додаткові поля (місце, контакти)
- Статистика відвідуваності подій
