# Міграція налаштувань клубу на Railway

## Що змінилось?

Раніше налаштування клубу (текст "Про ігротеку", інформація про оплату тощо) зберігались у файлі `.env`, який **не зберігається** на Railway між перезапусками.

Тепер ці налаштування зберігаються в **PostgreSQL базі даних**, що дозволяє:
- ✅ Редагувати інформацію через адмін-панель бота
- ✅ Зміни застосовуються моментально без перезапуску
- ✅ Налаштування зберігаються навіть після перезапуску/редеплою

## Що потрібно зробити?

### 1. Запустити міграцію

Після деплою нової версії на Railway, потрібно **один раз** запустити міграцію:

```bash
python migrate_club_settings.py
```

Це створить таблицю `clubsettings` в базі даних і перенесе існуючі значення з .env (якщо вони є).

### 2. (Опціонально) Встановити початкові значення через Railway

Якщо у вас ще немає значень в .env, можете встановити їх через Railway Variables:

1. Перейдіть в проект на Railway
2. Variables → Add Variable
3. Додайте (якщо потрібно):
   - `CLUB_ABOUT_TEXT` - повний текст про ігротеку
   - `PAYMENT_INFO` - повний текст про оплату
   - `PAYMENT_CARD_NUMBER` - номер картки
   - `PAYMENT_BANK_LINK` - посилання на банку

Після цього запустіть міграцію.

### 3. Використання через бота

Після міграції всі налаштування можна редагувати через адмін-панель:

1. Відкрийте бота
2. **⚙️ Адмін-панель**
3. **ℹ️ Редагувати інформацію про клуб**
4. Оберіть що хочете змінити:
   - **ℹ️ Текст 'Про ігротеку'**
   - **💳 Інформація про оплату**
     - Текст інформації про оплату
     - Номер картки
     - Посилання на банку

Всі зміни застосовуються **моментально** і зберігаються в базі даних!

## Технічні деталі

### Нова таблиця БД

```sql
CREATE TABLE clubsettings (
    id SERIAL PRIMARY KEY,
    setting_key VARCHAR UNIQUE NOT NULL,
    setting_value TEXT,
    updated_at TIMESTAMP DEFAULT NOW()
);
```

### Ключі налаштувань

- `CLUB_ABOUT_TEXT` - повний текст про ігротеку
- `PAYMENT_INFO` - текст про оплату
- `PAYMENT_CARD_NUMBER` - номер картки
- `PAYMENT_BANK_LINK` - посилання на банку

### Пріоритет значень

1. **БД** - якщо значення є в базі даних, використовується воно
2. **.env** - якщо немає в БД, використовується з .env/Railway Variables
3. **Дефолт** - якщо немає ніде, показується стандартний текст

## Для локальної розробки

При локальній розробці:
1. Запустіть міграцію один раз: `python migrate_club_settings.py`
2. Тепер ви можете редагувати налаштування через бота
3. Налаштування зберігаються в локальній БД (SQLite або PostgreSQL)

## Rollback

Якщо потрібно повернутись до старої версії:
1. Видаліть файли:
   - `migrate_club_settings.py`
   - `RAILWAY_SETTINGS_MIGRATION.md`
2. В `database/models.py` видаліть модель `ClubSettings`
3. В `database/crud.py` видаліть функції `get_setting`, `set_setting`, `get_all_settings`
4. Відновіть попередні версії файлів handlers

Але це **не рекомендується**, оскільки нове рішення набагато краще для Railway!
