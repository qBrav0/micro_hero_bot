# 🎯 Динамічне оновлення налаштувань клубу

## ✨ Що нового?

Тепер ви можете редагувати інформацію про клуб і оплату **прямо через бота**, і зміни застосовуються **моментально** без перезапуску!

## 🚀 Перший запуск (ВАЖЛИВО для Railway/Heroku/Render)

**Після деплою нової версії потрібно один раз запустити міграцію:**

```bash
python migrate_club_settings.py
```

Це створить нову таблицю в PostgreSQL для зберігання налаштувань.

### Для локальної розробки:

Якщо у вас локальна БД (SQLite), також потрібно запустити міграцію один раз після оновлення коду.

## 📝 Як редагувати налаштування

### Через адмін-панель бота:

1. Відкрийте бота
2. **⚙️ Адмін-панель**
3. **ℹ️ Редагувати інформацію про клуб**
4. Оберіть що змінити:
   - **🏢 Назва клубу**
   - **📝 Опис клубу**
   - **ℹ️ Текст 'Про ігротеку'**
   - **💳 Інформація про оплату**
     - Текст інформації
     - Номер картки  
     - Посилання на банку

### Що можна редагувати:

- ✅ **Назва клубу** - відображається в привітальному повідомленні та інших місцях
- ✅ **Опис клубу** - короткий опис, який бачать при старті бота
- ✅ **Про ігротеку** - повний текст який бачать користувачі в розділі "ℹ️ Про ігротеку"
- ✅ **Інформація про оплату** - текст який бачать в розділі "💳 Оплата"
- ✅ **Номер картки** - відображається в інформації про оплату
- ✅ **Посилання на банку** - посилання для онлайн-оплати

## 💾 Де зберігаються дані?

**В PostgreSQL базі даних**, таблиця `clubsettings`:

```
| id | setting_key           | setting_value              | updated_at          |
|----|-----------------------|----------------------------|---------------------|
| 1  | CLUB_NAME             | "Герої на полицях"        | 2024-01-15 10:25:00 |
| 2  | CLUB_DESCRIPTION      | "Ігротека настільних ігор"| 2024-01-15 10:28:00 |
| 3  | CLUB_ABOUT_TEXT       | "Текст про клуб..."       | 2024-01-15 10:30:00 |
| 4  | PAYMENT_INFO          | "Інформація..."           | 2024-01-15 10:35:00 |
| 5  | PAYMENT_CARD_NUMBER   | "5168..."                 | 2024-01-15 10:40:00 |
| 6  | PAYMENT_BANK_LINK     | "https://..."             | 2024-01-15 10:45:00 |
```

## 🔄 Як це працює?

1. **Адмін редагує** налаштування через бота
2. Бот **зберігає в БД** (PostgreSQL)
3. При наступному перегляді користувачі **бачать оновлену інформацію**
4. Зміни **зберігаються** навіть після перезапуску/редеплою

## ❗ Важливо

- Налаштування з `.env` файлу використовуються **тільки як дефолтні** значення
- Після редагування через бота, значення з БД мають **вищий пріоритет**
- На Railway/Heroku/Render `.env` файл **не зберігається**, тому всі налаштування мають бути в БД

## 🛠️ Для розробників

### Додавання нового налаштування:

1. В `handlers/admin.py` додайте обробник для редагування
2. Зберігайте через `set_setting(session, "KEY_NAME", value)`
3. Читайте через `get_setting(session, "KEY_NAME")`

### Приклад:

```python
# Збереження
from database import get_session, set_setting

async for db_session in get_session():
    await set_setting(db_session, "MY_SETTING", "значення")

# Читання
from database import get_session, get_setting

async for db_session in get_session():
    my_value = await get_setting(db_session, "MY_SETTING")
```
