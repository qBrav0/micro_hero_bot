# Функціонал нагадувань про записи

## Опис функції

Користувачі тепер можуть налаштувати автоматичні нагадування про свої записи на ігрові сесії через Telegram бота.

## Як це працює

### Для користувачів

1. **Налаштування нагадувань**
   - У головному меню з'явилася нова кнопка "🔔 Налаштування нагадувань"
   - Користувач може увімкнути/вимкнути нагадування
   - При увімкненні потрібно вказати за скільки годин до сесії отримувати нагадування (від 1 до 72 годин)

2. **Отримання нагадувань**
   - Нагадування приходять автоматично за вказану кількість годин до початку сесії
   - Якщо у користувача є кілька записів на один день, він отримає **одне нагадування**
   - Нагадування прийде за вказаний час до **найранішої** (першої за часом) сесії цього дня
   - У нагадуванні буде інформація про **всі записи** на цей день

3. **Приклад**
   ```
   Якщо користувач вказав "3 години" і має записи:
   - 15:00 - Каркассон
   - 18:00 - Монополія
   - 20:00 - Мафія
   
   Він отримає ОДНЕ нагадування о 12:00 (за 3 години до 15:00) 
   з інформацією про всі три сесії
   ```

### Технічна реалізація

1. **Зміни в базі даних**
   - Додано поля в таблицю `user`:
     - `reminder_enabled` (BOOLEAN) - чи увімкнені нагадування
     - `reminder_hours_before` (INTEGER) - за скільки годин нагадувати

2. **Нові компоненти**
   - `handlers/reminder.py` - обробка налаштувань нагадувань
   - `services/reminder_service.py` - логіка відправки нагадувань
   - FSM стейти для налаштування

3. **Фонова задача**
   - В `main.py` додана фонова задача `reminder_background_task()`
   - Перевіряє нагадування кожні 5 хвилин
   - Автоматично відправляє нагадування користувачам у потрібний час

4. **Алгоритм відправки**
   ```python
   Для кожного користувача з увімкненими нагадуваннями:
     1. Знайти всі активні реєстрації
     2. Згрупувати по датах
     3. Для кожної дати знайти найранішу сесію
     4. Перевірити чи настав час нагадування:
        reminder_time = session_start_time - reminder_hours_before
     5. Якщо зараз >= reminder_time (з точністю до 10 хвилин):
        - Відправити нагадування з інформацією про всі сесії цього дня
   ```

## Файли які були змінені/створені

### Створені файли:
- `handlers/reminder.py` - хендлери для налаштування
- `services/reminder_service.py` - сервіс відправки нагадувань
- `REMINDER_FEATURE.md` - цей файл (документація)

### Змінені файли:
- `database/models.py` - додані поля в модель User
- `database/migrations.py` - міграція для нових полів
- `keyboards/user_keyboards.py` - додана кнопка в головне меню
- `handlers/__init__.py` - додано імпорт нового роутера
- `services/__init__.py` - додано імпорт ReminderService
- `main.py` - додана фонова задача для нагадувань

## Налаштування

Функція працює автоматично після запуску бота. Міграції виконуються автоматично при старті.

## Тестування

Щоб протестувати функцію:

1. Запустіть бота
2. Натисніть "🔔 Налаштування нагадувань"
3. Увімкніть нагадування і вкажіть кількість годин (наприклад, 1 година для швидкого тесту)
4. Зареєструйтесь на ігрову сесію, яка буде через 1-2 години
5. Дочекайтесь нагадування

**Примітка:** Нагадування відправляються з точністю до 10 хвилин (інтервал перевірки - 5 хвилин).

## Логування

Всі дії з нагадуваннями логуються:
- Успішна відправка нагадувань
- Помилки при відправці
- Кількість користувачів з увімкненими нагадуваннями

Перевірити логи можна в файлі `bot.log`.
